> **Enterprise Low-Level Design (LLD) simulation** for an on-demand food delivery architecture (Zomato/Swiggy) demonstrating SOLID principles, Strategy, State, and Factory design patterns.

---

## 📌 Core Design Patterns & OOP Architecture

* **Strategy Pattern**: Dynamic delivery partner assignment (Nearest Partner, Batch Dispatch) and discount coupon calculators.
* **State Pattern**: Order lifecycle state transitions (`CREATED` ➔ `ACCEPTED` ➔ `PREPARING` ➔ `DISPATCHED` ➔ `DELIVERED`).
* **Factory Pattern**: Polymorphic payment processor handling Cards, UPI, Wallets, and Cash on Delivery.
